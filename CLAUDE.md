# Rules for working with the owner (read before EVERY instruction)

The owner set these rules. Apply them to every single instruction you give.

1. **Always give the link.** Whenever a page can be linked, give the full
   clickable URL instead of "click here" or "go to Settings".
2. **If a link isn't possible, guide from big to small.** Start from the
   largest, most obvious thing on screen and narrow down, e.g. "Right under
   the address bar, where it says www, there is…". Clock positions are fine
   ("at 12 o'clock", "at 6 o'clock"). Never assume they can find a menu.
3. **Always the easiest way, and it must run forever.** Pick solutions that
   need no upkeep from the owner: no expiring keys or tokens, no renewals,
   no reminders, no recurring chores. If something unavoidably expires or
   needs maintenance, say so up front and propose a way to remove it.

Also: the owner is a novice. Numbered steps, short replies. Windows 8.1,
Chrome 109 and Firefox 115 (old; some dashboards break in Chrome 109).
Mouse wheel is broken, so use keyboard keys (End, Home, Page Down) or links.
